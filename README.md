# 钊叔工具箱

Windows / macOS 共用的 Electron 桌面工作台，所有工具统一展示，不设工具箱账号。

## 已接入的功能

- 三公：选择 XLSX，登录快麦通，按精确货号和已确认别名查询淘宝 SKU 价格；查看逐行原因、导出核对明细，确认后备份并回填。保留公式及异常行，保存前检查原文件变化并回读验证。
- 丹姐：登录快麦 ERP，按起止月份查询原有 14 店、订单创建时间及售后完成时间口径，核对月度金额后导出横向月份 Excel。
- 检查更新：侧栏点击弹窗；发现新版后确认前往下载，不自动替换软件。发布地址尚未配置，当前会明确提示。

三公继续使用快麦通网页接口。丹姐原程序昨天成功使用 ERP 网页报表接口；开放平台的两个候选报表方法目前返回权限不足，统计口径也未完成对应，因此本版仍保留 ERP 登录。详见 OFFICIAL-API-STATUS.md。

## 登录复用

在工具箱的独立登录窗口完成登录。快麦通与 ERP 分别使用持久会话，退出时刷新本地存储；会话 Cookie 另以 Electron safeStorage 加密保存，并在下次启动恢复，不修改快麦的服务端有效期。退出账号会同步更新本机记录。服务器失效、异地登录或快麦要求验证时需要重新登录。

登录记录属于当前电脑用户，不随安装包分发，也不会在 Windows 与 Mac 之间自动同步。用户数据目录固定为系统 Application Support / AppData 下的 team-toolkit，软件改名或更新继续使用该目录。系统加密不可用时不退回明文保存。

## 验证范围

逻辑测试覆盖价格匹配、公式及其他 XLSX 内容保留、备份回读、源文件变更、报表分页及金额核对、加密会话保存与恢复，7 项测试通过。

2026-10-22 已在本机 macOS 的 Electron 桌面程序中实测：用户分别登录 ERP 和快麦通后，丹姐报表查询 14 店、2026 年 1—10 月成功，月度金额核对通过；三公的 3 行临时样本成功返回正常货号价格、无效 SKU 及未找到货号的逐行原因。退出进程再启动后，未打开登录窗口，两项查询再次成功；ERP 复测范围为 2026 年 1 月，金额与首次查询一致。验证只读查询，没有回填原工作簿。

随后正常退出开发程序，启动 dist/mac-arm64/钊叔工具箱.app，未再次登录，丹姐 2026 年 1 月及三公 3 行样本的查询均再次成功。打包程序与开发程序复用了固定用户数据目录。Mac 包为 Apple Silicon arm64，尚未签名或公证；DMG 由系统 hdiutil 生成并校验。

Windows 0.1 用户已确认安装并正常进入页面。0.2 的 Windows 安装、真实业务查询、重启复用、导出、文件占用与回填尚未实机验收；本机 macOS 的结果不替代 Windows 业务验收。

原始业务项目保持独立。安装包只含应用源代码、固定报表筛选配置和依赖，不含本机登录、开放 API 密钥、工作簿或历史响应。

## 启动与打包

安装依赖后运行 npm start，或双击 启动工具箱.command。Mac：npm run dist:mac；Windows：npm run dist:win。安装包名为 钊叔工具箱-版本-系统-架构。Mac 安装包在本机生成，Windows 生成 x64 包。

## 更新服务

在 update-config.json 的 manifestUrl 配置可信 HTTPS 清单地址后重新打包。清单包含三段版本号 version、说明 notes，以及 downloads 中的 darwin-arm64 / darwin-x64 / win32-x64 下载地址；下载链接仅接受 HTTPS。未配置时不会误报为最新版。目前尚未做真实在线升级验收。
