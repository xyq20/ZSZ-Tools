# 钊叔工具箱

Windows / macOS 共用的 Electron 桌面工作台，所有工具统一展示，不设工具箱账号。

## 已接入的功能

- 三公：选择 XLSX，仅对“价格”列空白且不含公式的行，按精确货号和已确认别名查询淘宝 SKU 价格；已有内容（包括 0、文字）和公式跳过查询并保留，同货号去重查询。页面显示待补与跳过行数，查看逐行原因、导出核对明细，确认后先备份再只填空白价格。没有待补行时不调用快麦接口；保存前检查原文件变化并回读验证。
- 丹姐：登录快麦 ERP，按起止月份查询原有 14 店、订单创建时间及售后完成时间口径，核对月度金额后显示底部合计并导出横向月份 Excel。
- 总表（双姐）：选择分级总表和运行日期，按原项目的每月 1 日/15 日规则分别查询实发数量、发货前退货率、发货后退货率与总退货率。查询后先显示预览和核对明细，关键货号及图片、工作表、公式校验通过后才能确认备份更新；支持月份滚动、自动改名与同节点重复更新。Python 核心来自独立项目 `1.快麦excel导入脚本`，来源提交记录在 `business/monthly-python/ORIGIN.md`；原项目保持独立。
- 工具导出的核对明细 Excel 内容均水平、垂直居中；总表更新保留其原有图片与排版。日期选择与文件打开、保存窗口使用中文，Windows 安装向导使用简体中文。
- 检查更新：侧栏点击弹窗，从 GitHub Releases 查询正式新版，按系统和芯片选择安装包；确认后前往下载，再运行安装包更新软件。

三公继续使用快麦通网页接口。丹姐原程序昨天成功使用 ERP 网页报表接口；开放平台的两个候选报表方法目前返回权限不足，统计口径也未完成对应，因此本版仍保留 ERP 登录。详见 OFFICIAL-API-STATUS.md。

## 登录复用

在工具箱的独立登录窗口完成登录。快麦通与 ERP 分别使用持久会话，退出时刷新本地存储；会话 Cookie 另以 Electron safeStorage 加密保存，并在下次启动恢复，不修改快麦的服务端有效期。退出账号会同步更新本机记录。服务器失效、异地登录或快麦要求验证时需要重新登录。

登录记录属于当前电脑用户，不随安装包分发，也不会在 Windows 与 Mac 之间自动同步。用户数据目录固定为系统 Application Support / AppData 下的 team-toolkit，软件改名或更新继续使用该目录。系统加密不可用时不退回明文保存。

0.3.1 起，登录窗口与工具箱主窗口独立；最小化登录页会返回工具箱，点击 Dock 图标或登录按钮可恢复窗口。总表通过内置快麦页面自身的请求环境查询，并跟随登录跳转到实际 ERP 域名；不依赖用户安装的 Chrome、Edge 或 Safari。

## 启动与打包

安装依赖后运行 npm start，或双击 启动工具箱.command。Mac：npm run dist:mac；Windows：npm run dist:win。安装包名为 钊叔工具箱-版本-系统-架构。Mac 安装包在本机生成，Windows 生成 x64 包。

0.3.0 起，总表（双姐）的 Python 运行环境随对应平台的完整安装包分发，同事不用安装 Python 或 Chrome。源码开发/打包前运行 `npm run prepare:runtimes` 准备固定版本的私有运行环境；已存在的运行环境会复用，首次下载按 SHA-256 验证。运行环境目录不提交 Git。Mac Apple Silicon 使用 Astral 的 CPython 3.12.14，Windows x64 使用 Python 官方 3.12.10 嵌入式包。业务模块与运行环境通过 extraResources 安装到 Resources 外部目录，避免从 app.asar 内执行 Python。总表和丹姐共用本机 ERP 登录分区，查询分别使用各自原有接口及筛选条件；Cookie 只由 Electron 管理，不传给 Python。

## GitHub 发布和更新

更新源固定为 https://api.github.com/repos/xyq20/ZSZ-Tools/releases/latest，无须同事登录 GitHub。仅识别正式 Release，草稿和预发布版本不作为新版。已安装的 0.2.0 没有配置更新地址，需手动安装 0.2.1 一次；后续可通过“检查更新”发现新版。检查更新仍使用弹窗，下载和覆盖安装由用户确认执行。

发布时先更新 package.json 与 package-lock.json 的三段版本号，测试并打包；将对应提交推送后，创建草稿 Release v版本号，上传并验证所有安装包后再转为正式版本。附件名称使用 钊叔工具箱-版本号-win-x64.exe、钊叔工具箱-版本号-mac-arm64.dmg 或 钊叔工具箱-版本号-mac-x64.dmg；GitHub 会将中文前缀去掉，更新器同时接受 -版本号-系统-架构 的实际附件名。应用自动按当前系统、芯片寻找对应附件；缺少对应包时会提示该系统尚未发布。安装包放在 Release 附件，不提交到源码仓库。
